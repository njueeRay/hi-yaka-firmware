# 10 产品与 PRD

## 北极星

HiYaKa 是 Wi-Fi-only、非触控屏幕、实体导航的便携 AI 终端。一级主线为 AI 语音对话和可靠本地录音；NFC、IMU、RGB、振动、屏幕和按键服务于这两条主线。

## 当前范围

- 必须：配网、对话、录音、文件恢复、实体导航、NFC 只读、用户确认 OTA、诊断和离线降级。
- 不做：4G/SIM、5 GHz Wi-Fi、主动蓝牙音频、摄像头、触摸和游戏。
- 未决：按键最终语义、录音格式/时长、NFC 业务、离线范围、量化延迟与续航。

完整产品需求以 [yaka-3.0-prd.md](yaka-3.0-prd.md) 为当前工作基线，并同步到飞书 `01 产品与使用 / 01 产品需求与交互状态`。处理产品范围、场景、交互、需求 ID、验收或未决产品输入时，必须读取该完整 PRD，不要只依赖本 reference 的摘要。

当前角色、已冻结/暂行决定、待 Owner 裁决和团队输入见 [yaka-3.0-owner-decisions-and-todos.md](yaka-3.0-owner-decisions-and-todos.md)；维护规则见 [15-owner-decisions-and-todos.md](15-owner-decisions-and-todos.md)。本仓库固件 PRD 只把产品目标翻译成可实现、可测试的固件合同，不重新定义产品。

## 状态口径

用 `冻结 / 候选 / TBD / 不做` 管理产品决定；用 `未实现 / 已实现未实测 / 实板通过 / 降级 / 失败` 管理工程能力。两套状态不得混用。

## 同步要求

产品 PRD 有效变更时，同时检查：飞书产品 PRD、固件 PRD、产品手册、Owner 决策台账、硬件接口表和验收矩阵。Owner 决策一旦生效，应从“待决策”移入“已冻结/暂行”，并同步到飞书“决策与版本记录”；普通工程任务不得混入 Owner 待办。
