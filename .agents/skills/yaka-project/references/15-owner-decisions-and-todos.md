# 15 当前角色、Owner 决策与待办

## 读取入口

处理“当前由谁负责”“还有哪些需要 Owner 回答”“某项是否已经决定”“哪些只是工程执行”时，读取：

- 本地当前台账：[yaka-3.0-owner-decisions-and-todos.md](yaka-3.0-owner-decisions-and-todos.md)
- 飞书协作副本：`YaKa 3.x / 03 协作、决策与调研 / 当前角色、Owner 决策与待办`
- 正式历史决定：飞书 `02 决策与版本记录`

## 职责边界

- 当前台账只保留已冻结决定、暂行基线、待 Owner 决策和待团队输入。
- 正式生效且需要长期追溯的结论同步到“决策与版本记录”。
- 产品行为同步到产品 PRD；固件工程任务同步到固件 PRD；测试/缺陷同步到测试与发布记录。
- 已关闭的 ECO、旧硬件阻断、过期仓库/构建环境问题进入“已关闭或被取代”，不得继续显示为当前待办。

## 更新规则

1. 使用稳定 ID，不复用旧 ID 表达另一件事。
2. Owner 回复后记录结论、日期、影响文档和仍需验证的边界。
3. 工程能够自主完成的可逆任务不升级为 Owner 决策。
4. 待办必须有责任角色和可观察的关闭条件；仅写“继续研究”不算有效待办。
5. 每次更新回读飞书副本，并同步 `FEISHU_SYNC_REGISTRY.md`。
