# HiYaKa 共享 I²C 隔离诊断

仅用于已拆除 L7、扬声器断开且温度正常的受控样机。构建目标是 ESP32-C6 / ESP-IDF 6.1。诊断保持 GPIO23/PA_EN 为低电平，不启动 LCD、音频、马达、TF 或 NFC；不会向 PN532 发送命令。

程序按 100 kHz → 25 kHz → 25 kHz → 100 kHz 的顺序，分别测 PCA9557 单独读、ES7210 单独读、分开写寄存器地址再读、以及多器件交替访问。后者仅向 PCA9557 的输出锁存寄存器反复写安全值 `0x40`，保持马达与功放关闭；读取 PCA9557 `0x01`、ES7210 `0x0B`、QMI8658A `0x00`，并探测 PCA9557 `0x19`、ES7210 `0x41` 与 ES8311 `0x18`。每一项按成功、NACK、超时及其它错误计数。地址探测的总线速率不纳入 25/100 kHz 定量比较；速率比较以设备句柄上的读写事务为准。该程序运行时 LCD 画面不会刷新，`0x40` 会把背光控制锁存置低，可能使已有画面暂时消失；实验后恢复产品镜像。

这项对照能判断故障是否仍在无显示、无音频任务时发生，是否主要表现为地址应答、单器件寄存器读、多器件交替读写中的哪一种异常，以及降低速率是否明显改善。拆成两笔的读法是**诊断对照**，并非直接推荐修改产品驱动；PCA9557 和 ES7210 数据手册都描述了带重复起始的寄存器读。`ESP_ERR_INVALID_RESPONSE` 只能说明该事务收到 NACK，不能单独定位是地址字节还是数据字节。静态 GPIO 高电平、地址级 ACK 与一次读写成功也不能证明总线波形、A0 电平或芯片焊接合格。

当前 PN532 SET0/SET1 悬空，实验不修改其硬件状态，因此不能排除它对共享总线的干扰；若 A0 测量和软件统计矛盾，需要同步实测 R8 的 A0 侧电压。实验结束应恢复既有横屏诊断镜像并校验。
