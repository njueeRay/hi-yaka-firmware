# HiYaKa 换入样机复测记录（2026-11-05）

> 范围：换入一块此前未烧录的样机；操作者确认 L7 已拆、MASTER ON、无异常发热，显示屏 FPC 已接。TF 卡起初未插，后在运行中插入并通过复位挂载。实物序列号、PCB 修订及是否曾返修未独立核对。本记录是新的实板证据，不覆盖此前样机的结论。

## 测试基线与烧录

- 主控为 ESP32-C6 rev 0.2、16 MiB Flash；上电时 ROM 连续报告 `invalid header: 0xffffffff`，说明本轮上电前没有可启动镜像。
- 使用 Windows COM5/CH340K 和 115200 baud 烧录；首次完整镜像在传输途中失联。随后按 Flash 地址分段写入：`0x000000–0x2fffff` 的引导/分区/应用内容及 `0x800000–0x943fff` 的资源内容，所有实际含数据的分段均得到 esptool 写后哈希校验。`0x300000–0x7fffff` 在首次完整烧录时已擦除，原镜像该区全为 `0xff`。
- 完整实验镜像来自代码基线 `f484b08`，SHA-256 `ACA9584B7B678A190E5DD5FB3E5896705EE7776D1BB17FED3BDC48AAC168F5BD`；该镜像仅用于全外设复测。独立双工 25 秒麦克风对照应用 SHA-256 `40B9038198A0A1108C235C55C6BF8D510F105B5DDA5BAF01EE3A12618032F526`。结束后恢复无屏幕实验应用 SHA-256 `8A140D79FDFF64EEDCB0F0434746C4AB9000881F9C0FB6D0E6036FE2FD1FFBA7`，应用区各段写后校验通过，启动日志显示 `hi-yaka-lab-headless/2.5.2`。
- 传输曾在不同地址两次中断，另一次 57600 baud 尝试未能启动烧录 stub；分段 115200 baud 完成写入。尚无证据将传输中断归因于新板电源、USB 线或 CH340K，不能把它写成已定位的硬件故障。

## 模块结果

| 模块 | 换入样机证据 | 本轮结论 |
|---|---|---|
| 启动及功放安全态 | ROM 从空 Flash 变为正常启动；`GPIO23/PA_EN` 启动后强制低。L7 已由操作者拆除，期间报告无异常发热。 | 非功放测试 `CONDITIONAL GO`；扬声器未测。 |
| RGB、马达、按键 | 自检日志执行红→绿→蓝与 80 ms 短振；操作者看到灯光或感到振动。恢复版重启后，两次 `ACT_B PRESS` 出现在串口，红灯由操作者确认亮后熄灭；`PWR_A` 短按由操作者确认产生短振，但此次按键未落入串口采集窗口。其他按键未逐一复验。 | 自动反馈、`ACT_B` 与 `PWR_A` 的上述交互有 L1 证据；其余按键仍待复验。 |
| I²C 与 IMU | `0x18/0x19/0x41/0x6B` 应答；QMI8658A WHO_AM_I=`0x05`，加速度、角速度和温度返回数值。 | 基础探测 L1；运动校准未测。 |
| TF | 起初未插卡，驱动报告 `ESP_ERR_TIMEOUT`；后插卡并重启，日志确认挂载 `/sdcard`，`act-b-001.wav` 创建并关闭，写入 162560 字节。 | TF 挂载与文件写入 L1；音频内容因麦克风无数据仍为无效。 |
| NFC | `0x24` 冷启动和延时探测均 NACK；PN532 固件版本请求三次失败。换成无屏幕应用后仍 NACK。 | `FAIL`，与此前样机现象一致；根因仍未知。 |
| 显示屏 | FPC 已接，操作者确认完全无背光；PCA9557 的背光锁存位可写入并读回，但不等于 Q10 栅极出现高电平。完整应用运行约 13.8 秒后出现 LCD I²C 传输超时，约 23.8 秒 LVGL 任务触发看门狗。 | `FAIL`；原设计缺上拉是高置信度解释，换入样机的修订、R85/Q10 均未单独核对；显示任务另有运行稳定性现象待区分。 |
| 双麦采集 | 完整应用 5 秒采样 `160000` 点，`peak=0`、`mean_square=0`；独立双工保持 25 秒仍只得到固定 `-1`，GPIO13 20 ms 内 0 上升沿，弱下拉后全 0、弱上拉后全 `-1`。MCU 端 MCLK/BCLK/WS 有时钟，ES7210 `0x41` 可读，`0x0B=0`。TF 插入后，`ACT_B` 录音 WAV 关闭时再次报告 `peak=0`。 | `FAIL`；没有有效主动数据到达主控，不能据此判定 U12、焊接或走线中的哪一处是根因。 |

换入样机上 NFC、麦克风、显示屏三项均复现故障，提高了共同设计、装配条件或固件配置因素的优先级；**并未证明所有板卡必然失效，也未关闭各自根因**。完整显示应用的 LVGL 看门狗只在本轮有限窗口观察到一次；无屏幕恢复应用的启动和短时串口观察正常，不等于长稳通过。

恢复版首次运行时，操作者按 ACT_B 未见红灯，对应监听窗口也没有串口输出；插卡并复位后，ACT_B 的两次事件和红灯亮灭均复现正常。首次无响应的原因未知，不能把“复位后恢复”解释为已修复或已定位。
