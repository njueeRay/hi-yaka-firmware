# 专项问题分析：HiYaKa 麦克风无有效数据

> 问题编号：`HIYAKA-AUDIO-INC-001`<br>
> 级别：`P1`<br>
> 首次确认：2026-11-04<br>
> 影响范围：HiYaKa R1.6 原开发样机；2026-11-05 换入样机复现，PCB 修订未独立核对<br>
> 当前状态：录音控制与 WAV 留样可用，原始音频数据 `FAIL`，根因未确认

## 1. 结论

- **已确认：**ACT_B 两次短按能启停录音，红灯提示及 TF WAV 写入/关闭正常；WAV 峰值为 0，麦克风业务功能未通过。
- **已确认：**ESP32-C6 内部 I²S 回环能接收已知字样，主控端 MCLK/BCLK/WS 正常；接 ES7210 后，GPIO13 无数据边沿，原始样本固定全 0 或全 -1，且随 GPIO13 内部弱上下拉改变。**主控目前没有获得有效主动数据，置信度高，仅限 MCU 端。**
- **未知：**U12 供电/时钟是否到达芯片脚、U12.11 是否实际输出、R65 两侧及 GPIO13 实物连通均未测；ES7210 状态寄存器 `0x0B` 在不同实验读到 0 与 2。不能认定 U12 已坏，也不能认定只是软件配置问题。
- **决策：**已隔离功放的样机可继续非录音模块测试（`CONDITIONAL GO`）；双麦录音、语音对话和整机发布 `NO-GO`，M3/M4 相关验收不关闭。

## 2. 现象

早期三麦 TDM、标准双麦单声道与双声道实板实验的原始 DMA 均全 0；ACT_B 红灯录音产生的 WAV 均无有效声波。后续独立软件 A/B 在 16 kHz、双槽 16 位条件下，ES7210 单 RX 默认/24 dB 增益以及原双工均只采到固定 `-1`；下拉 GPIO13 后变为全 0，上拉后全 -1。独立双工保持 25 秒仍如此，GPIO13 在 20 ms 内计数 0 上升沿。两种固定码值均不属于正常的环境安静底噪。

ES7210 地址 `0x41` 应答，寄存器可读。人工按键的有屏幕实验在约 22.6 秒读得 `0x0B=2`，但仍无音频；本轮独立无屏幕实验在约 25.7 秒读得 `0x0B=0`。操作者曾在录音亮灯时报告 R42/R45 附近约 2.83 V，但未逐一确认四个焊盘与测量时刻。断电跨件读数 R63/R64 约 0 Ω、R65 约 51 Ω。

2026-11-05 换入样机的完整固件采集 5 秒、160000 个点，峰值和均方值均为 0。独立双工 25 秒对照仍只读到固定 `-1`；MCU 端 MCLK/BCLK/WS 有时钟而 GPIO13 20 ms 内 0 上升沿；弱下拉后样本全 0、弱上拉后全 `-1`，ES7210 `0x0B=0`。这使原开发样机的现象在另一块实板复现。随后 TF 卡插入并复位，两次 ACT_B 正常启停录音、红灯亮灭，WAV 创建及关闭成功，但 `peak=0`。本轮没有测 U12 引脚或 R65 两侧波形。

## 3. 排查分析

冻结 R1.6 原理图/PCB 与前次活体网表显示：两颗 ZTS6216 麦克风进入 U12/ES7210 MIC1/MIC2；U12.11/SDOUT1 经 R65（51 Ω）到 ESP32-C6 GPIO13。旧版已验收 S3 板使用同类 ES7210 双麦拓扑，但主控、引脚、采样格式及驱动版本不同，不能替当前板证明实物连通。

| 对照 | 实测 | 对判断的作用 |
|---|---|---|
| MCU 内部 I²S TX→RX 回环，避开 U12/GPIO13 | 接收 4096 字，命中已知字样 2048 字，重复 `PASS` | 排除主控 I²S 接收/DMA 完全失效；未检验外部数据路径。 |
| 仅 ES7210 RX，不分配 TX/ES8311 | 读取 API 成功，但 512 字固定 `-1`；增益变化无效 | 双工配对不是唯一原因；“非零即录音成功”不成立。 |
| GPIO13 弱下拉/弱上拉 | 样本分别固定全 0/全 -1 | 数据输入进入当前 I²S 采样链，强烈支持当前无压过弱拉的外部有效驱动；不能区分 U12 未输出与中间开路。 |
| 跳过全部前置 A/B 的独立双工 | 保持 25 秒仍固定码值，MCU 端时钟约 4.096 MHz/512 kHz/16 kHz，GPIO13 无边沿 | 前置实验残留和短暂启动延迟不足以单独解释；不证明时钟到达 U12。 |

ES7210 原厂手册把 `0x0B=0` 解释为 power-down、2 为 normal；当前不同实验互相冲突。I²C 应答及寄存器选通/未静音，只证明控制接口可访问，不证明全部电源脚和 SDOUT1 驱动。R63/R64/R65 的跨件电阻值不证明芯片焊盘、过孔、两端走线全路径连续。综合排序：**U12 未满足有效输出条件**与**U12→GPIO13 实体链路异常**同为中等置信度假设；单纯 WAV 封装、音量增益或按键映射已被削弱。

## 4. 解决方法

1. **当前样机：**维持功放 L7 断开、GPIO23/PA_EN 关闭，扬声器空置；保留 `hi-yaka-lab-audio-ab` 与独立 `hi-yaka-lab-audio-baseline` 作为诊断构建，以原始 PCM、固定码值分布和 TF WAV 交叉复核。对 `0x0B=0/2` 两类实验只改变一个启动条件，比较完整寄存器、I²C 错误和初始化顺序。该软件工作可以继续缩小范围，**不是已验证修复**。
2. **下一轮维修台判别：**同一录音窗口量 U12.6/VDDP、U12.7/VDDD、U12.22/VDDA、U12.23/VDDM；U12.5/MCLK、U12.9/SCLK、U12.10/LRCK；U12.11/SDOUT1、R65 两侧与 GPIO13 的同步波形。若芯片脚电源/时钟异常，先修供电或时钟；若 U12.11 有数据而 GPIO13 无，修焊盘/串阻/过孔/走线；若电源时钟正常、`0x0B=2` 却 U12.11 不输出，再核对三态/slot/偏置与 U12 焊接或芯片本体；若 GPIO13 有波形而 DMA 仍固定，再查 C6 GPIO matrix 和 I²S 输入配置。
3. **下一版永久修复：**只依据上述分支的实测根因做对应 ECO、器件或驱动修改，再重复双麦、播放参考及并发录音验证。当前不能预先把“换 U12”“换 R65”或“改 PCM 后处理”定为量产方案。只有万用表时可核对安全可触的直流电源与断电连通，不能用直流均值替代数字波形。

## 5. 验证与关闭标准

- [ ] 固定根因、返修位置或代码差异，并用同条件 A/B 重复证明；
- [ ] 多次冷启动 U12 状态、电源/时钟及 U12.11→GPIO13 数据链一致；
- [ ] MIC1/MIC2 原始 PCM 分别随声源变化，静音有合理底噪，不再固定全 0/全 -1；
- [ ] ACT_B 录音 WAV 可回放且两路对应正确；连续录音、关闭文件和重新启动后仍正常；
- [ ] 不引入 U11 发热或 I²C/其它外设回归，保存波形、原始日志、固件 SHA 和样机编号，再评估 M3/M4。
