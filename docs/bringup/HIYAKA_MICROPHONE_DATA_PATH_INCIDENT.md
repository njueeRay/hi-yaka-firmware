# 专项问题分析：HiYaKa 麦克风无有效数据

> 问题编号：`HIYAKA-AUDIO-INC-001`<br>
> 级别：`P1`<br>
> 首次确认：2026-11-04<br>
> 影响范围：HiYaKa R1.6 原开发样机及换入样机<br>
> 当前状态：录音操作与文件写入可用，但音频数据没有到达主控；根因未确认

## 1. 结论与业务影响

- **结论：**按键、录音状态和 TF 文件流程曾正常，但主控未收到有效麦克风数据；当前样机还出现共享 I²C 不稳定，先阻断了 ES7210 初始化。后续数据路径根因仍未确认。
- **影响：**双麦录音、语音对话和所有依赖麦克风的业务不可用；TF 卡写入本身可继续测试。
- **阶段决策：**录音功能与整机发布 `NO-GO`；其它模块在功放隔离条件下 `CONDITIONAL GO`。
- **下一步：**先把 PN532 模式脚和 PCA9557 地址脚恢复到可确认的固定电平，使 ES7210 寄存器读写稳定；随后再测 U12 到 GPIO13 的数据链。

“主控端没有收到有效主动数据”置信度：**高**；“U12 未输出”和“U12→GPIO13 实体链路异常”均为**中置信度**分支。

## 2. 现象

两块样机都能通过 ACT_B 启停录音、切换红灯并在 TF 卡创建和关闭 WAV 文件，但 WAV 峰值为 0，无法回放出有效声音。多种采样和增益设置下，原始样本固定为全 0 或全 `-1`；改变 GPIO13 内部弱上拉/下拉后，固定码值随之改变，GPIO13 没有观察到音频数据边沿。

主控内部 I²S 回环能够接收已知数据，主控端 MCLK/BCLK/WS 有时钟。ES7210 地址 `0x41` 可访问，但状态寄存器 `0x0B` 在不同实验中出现 0 和 2；尚未测量时钟是否真正到达 U12 引脚，也未比较 U12.11、R65 两侧和 GPIO13 的同步波形。

2026-11-12 当前样机的同板对照新增一项前置阻断：无屏幕镜像及专用仅输入镜像均出现 I²C 失联。专用镜像的主控 I²S 内部回环通过，但 ES7210 初始化寄存器写入失败，未进入有效 PCM 采集；跳过启动 I²C 扫描后故障仍复现。此次不能用“无 PCM”推断 U12.11 或 R65 的实体故障。

## 3. 排查分析

### 3.1 因果链

```text
ES7210 未产生 SDOUT，或 SDOUT 到 GPIO13 的实体链路中断
→ GPIO13 只呈现内部弱拉决定的固定电平
→ I²S DMA 得到全 0 / 全 -1
→ WAV 文件能创建但没有有效声音
```

### 3.2 已确认事实

- ACT_B、录音状态灯、TF 文件创建和关闭正常，按键映射及文件系统不是当前直接原因。
- MCU 内部 I²S 回环重复通过，排除主控 I²S 接收/DMA 完全失效。
- MCU 端 MCLK/BCLK/WS 可见，而 GPIO13 无数据边沿；弱上拉/下拉能改变固定码值，说明 MCU 采样端没有获得足够强的外部主动驱动。
- 冻结原理图和 PCB 显示 U12.11/SDOUT1 经 R65（51 Ω）到 ESP32-C6 GPIO13；静态网表正确不等于实板端到端连通或 U12 已输出。
- I²C 应答和寄存器可读，只能证明控制接口可访问，不能证明 U12 全部电源、时钟及 SDOUT 工作。
- 当前样机即使不运行屏幕和启动全地址扫描，PCA9557 及 ES7210 的控制写入也会失败；PN532 SET0/SET1 此时悬空，R8/A0 对地电压曾在 0 与 3.3 V 间变化。共享 I²C 条件尚未稳定，不能把 ES7210 控制失败定为单一芯片故障。

### 3.3 已排除、削弱与待验证分支

| 分支 | 当前判断与证据 | 置信度 | 最短判别方法 |
|---|---|---|---|
| 共享 I²C 绑带或总线异常阻断初始化 | 同板无屏幕、跳过扫描后仍出现 PCA9557/ES7210 写入失败；PN532 模式脚悬空，R8/A0 曾测得不稳 | 高：存在前置阻断；具体硬件根因未知 | 固定 PN532 模式脚，核对 R8/A0 与 `0x18/0x19` 身份，连续读写 U3/U12 寄存器。 |
| U12 未满足有效输出条件 | `0x0B` 状态不一致，尚未量芯片脚电源/时钟和 U12.11 | 中 | 同一录音窗口测 U12 电源、时钟、状态和 U12.11 波形。 |
| U12.11 到 GPIO13 焊接、R65、过孔或走线异常 | 网表正确，但无端到端同步波形；GPIO13 只受弱拉影响 | 中 | 同时比较 U12.11、R65 两侧和 GPIO13，并做断电连通。 |
| MCU I²S/DMA 完全失效 | 内部回环通过，MCU 时钟存在 | 低 | 仅当 GPIO13 已有正确波形但 DMA 仍固定时再查 GPIO matrix。 |
| WAV 封装、增益或按键问题 | 原始 DMA 已固定，文件流程正常，增益变化无效 | 低 | 不再作为首要分支。 |
| 功放 L7 拆除导致麦克风失效 | L7 位于扬声器功放输出链，不在 ES7210 采集路径 | 低；仅保留返修误伤可能 | 检查返修区域是否机械损伤相邻网络，无需恢复 L7 验证录音。 |

### 3.4 2026-11-12 同板对照：先修复控制通信

无屏幕基线、旧镜像及专用仅输入镜像均未能在当前样机完成音频初始化。专用镜像的主控 I²S 内部回环通过，但 ES7210 首批寄存器写入失败；跳过启动 I²C 扫描后，PCA9557 仍有写入与读回失败，ES7210 仍无法打开。由此确认：屏幕刷新和启动扫描都不是本次控制通信失败的必要条件；本次没有有效 PCM 结果，不能用来判断 U12.11 或 R65 是否故障。

当前 PN532 的 SET0/SET1 电阻均已拆除、模式脚悬空；R8/A0 上拉一端实测 3.3 V，另一端曾在 0 与 3.3 V 间变化。具体是模式绑带、地址脚、焊接还是总线波形造成不稳定，仍未知。镜像、日志和哈希见[同板对照证据](2026-11-12-pca-audio-shared-i2c-ab-evidence.md)。

## 4. 解决方法

### 4.1 当前 PCBA 止损与判别

继续保持功放 L7 断开、GPIO23/PA_EN 关闭和扬声器空置，避免功放故障干扰诊断。当前板先在完全断电后修复 PN532 模式脚悬空状态并核对 R8/A0；在 ES7210 控制读写连续稳定前，暂停重复烧录麦克风实验镜像。保留 A/B 固件作为后续诊断工具，但主报告只以原始 PCM、GPIO13 波形和 TF WAV 作为结果，不以“读取 API 成功”判断录音成功。

维修台按以下顺序同步测量：

1. U12.6/VDDP、U12.7/VDDD、U12.22/VDDA、U12.23/VDDM；
2. U12.5/MCLK、U12.9/SCLK、U12.10/LRCK；
3. U12.11/SDOUT1、R65 两侧和 GPIO13。

若 U12.11 有数据而 GPIO13 没有，修复焊盘/R65/过孔/走线；若电源时钟正确且状态正常但 U12.11 不输出，再核对配置、焊接和芯片本体。当前不建议盲目更换 U12 或 R65。

### 4.2 下一版永久修复

只把实测确认的根因转成原理图、PCB、BOM、SMT 工艺或驱动 ECO；完成双麦、播放参考、连续录音和并发测试后再纳入量产基线。

### 4.3 禁止采用的做法

- 不用 WAV 文件存在或样本“非零”代替有效音频判定；
- 不用万用表直流均值代替 I²S 数字波形；
- 在没有分段波形证据前，不把“换 U12”“恢复 L7”或“修改 PCM 后处理”定为修复方案。

## 5. 验证与关闭标准

- [ ] 固定根因、返修位置或代码差异，并用同条件 A/B 重复证明；
- [ ] 多次冷启动后 U12 状态、电源、时钟及 U12.11→GPIO13 数据链一致；
- [ ] MIC1/MIC2 原始 PCM 分别随声源变化，静音时有合理底噪，不再固定全 0/全 `-1`；
- [ ] ACT_B 录音 WAV 可回放、两路对应正确，连续录音、关闭和重启后仍正常；
- [ ] 不引入 U11 发热或其它 I²C/外设回归，并保存波形、日志、样机编号和固件 SHA。
