> 文档状态：工作主文档 v1.0  
> 当前硬件基线：YaKa v3.0，封存复审 R1.6（2026-10-21）  
> 当前发布结论：原理图/PCB `GO TO PROTOTYPE`；制造发布 `CONDITIONAL GO`  
> 最近更新：2026-10-29

本文是研发入口，不替代活体 EDA、冻结制造包或原始审计。详细论证以文末版本化附件为准；本文维护当前有效结论、固件接口、制造/bring-up 门禁和持续研发日志。

## 1. 权威性与变更原则

当前 EasyEDA Pro 工程及其原理图/PCB 绑定为实现真值；R1.6 复审为当前封存证据；精确料号厂商资料决定器件电气要求。历史 YaKa、旧聊聊鸭 PCB、截图和旧固件只能用于发现线索。

硬件修改必须沿以下链路回归：

```text
产品需求 → 模块功能 → 精确器件/封装 → 电源/网络/引脚
→ 原理图端点 → PCB 焊盘/走线/回流路径 → 固件绑定/时序
→ BOM/SMT/总装 → bring-up/故障注入 → 产品行为
```

## 3. 固件接口契约

### 3.1 共享 I²C

- I²C0：GPIO10 SDA、GPIO11 SCL；首板 100 kHz；
- ES8311 `0x18`、PCA9557 `0x19`、PN532 `0x24`、ES7210 `0x41`、QMI8658A `0x6A`；
- 每次访问必须有超时；单个非关键器件故障进入 degraded，不形成无限重启。

PCA9557 上电顺序：Output Port=`0x40` → Configuration=`0x38` → readback。IO3/IO4/IO5 初始保持输入，IO4 的历史 `PWR_EN` 语义未再次冻结前不主动驱动。

### 3.2 显示与 TF

- LCD：GPIO6 MOSI、GPIO7 SCLK；实际功能以端点为准，不以历史网名推断；
- TF/SDSPI：GPIO18 MOSI、GPIO19 CLK、GPIO20 MISO、GPIO15 CS；无 card-detect，以挂载结果决定能力。

### 3.3 音频

ES7210 的双麦与播放参考 slot 必须用原始 PCM 验证。小智 C6 LiteAudioEngine 的上行只取第一通道，因此播放参考不得排在第一通道。HT8691R 必须在 ES8311/I²S 稳定后使能，停止时先关闭 PA。

### 3.4 电源边界

MASTER_SW 在 OFF 时切断整机，PWR_A/PWR_B 不能实现冷启动。LGS4056H 自治充电，但 MCU 无完整 DONE/VBUS 状态链；UI 只能展示经实测支持的电压/充电提示。

## 4. 原理图与 PCB 当前结论

- R1.6 未发现未关闭电气 P0；原理图↔PCB 292/292 唯一身份、端点与装配属性已复核；
- PCB DRC 当前为 0，但 DRC 不替代功能、结构、声学、RF、热和制造验证；
- 振动器已冻结为 3 V ERM；充电完整状态不可观测被接受为产品能力边界；
- 制造发布仍为 `CONDITIONAL GO`：最终 Gerber/Drill/BOM/CPL、匹配页、库存和人工预览必须签核。

## 5. SMT、采购与总装

SMT 输入必须锁定精确 MPN、C 编号、封装、DNP、位号和每板数量。LCD、电池、扬声器、NFC 天线、TF、USB 数据线和结构件属于外购总装/验证物料，不应误混入贴片 BOM。库存快照有时效性，下单前重新核对。

冻结发布包沿用：工程归档、fabrication、assembly、sourcing、audit、order、evidence、manifest 和 SHA256SUMS 分层目录。任何文件重新导出都必须重算 manifest/哈希。

## 6. 首板 bring-up 门禁

1. 空载目检和限流供电，确认 3.3 V、电源开关和静态电流；
2. USB/CH340K、BOOT/RESET、串口和 C6 下载；
3. Flash ID/容量、擦写和 DIO；
4. I²C 五地址和 PCA9557 安全态；
5. LCD、RGB、五灯链、马达；
6. ADC 键每键不少于 100 次原始值并标定阈值；
7. TF 连续写入、校验和随机硬切恢复；
8. ES7210/ES8311/PA 通道、底噪、增益、假负载和扬声器功率；
9. NFC 天线读距、IMU、电池/充电和峰值负载；
10. Wi-Fi + LCD + RGB + 音频 + TF 整机并发压力。

## 7. 固件耦合矩阵维护字段

每个外设记录：精确器件、总线/地址或 CS、信号到 GPIO、工作电压、pull/极性、时钟/模式、rail/enable/启动延时、IRQ/wake、驱动来源、init/active/fault/sleep/update/test 生命周期。
