# YaKa 3.0 硬件权威附件索引

> 本目录保存从 YaKa 项目资料区复制的版本化快照。活体 EasyEDA 工程优先于附件；附件禁止静默改写，更新应建立新版本并重算 SHA-256。

| 文件 | 角色 | 基线 |
|---|---|---|
| `yaka-3.0-final-schematic-pcb-reaudit-2026-10-21.md` | 原理图、PCB、PRD、固件接口全链路最终复审 | R1.6，authority |
| `yaka-3.0-schematic-audit-and-eco-spec.md` | 逐模块原理图审计与 ECO 依据 | supporting authority |
| `yaka-3.0-pcb-comprehensive-audit-and-eco-spec.md` | PCB 布局、走线、机械、DFM 审计 | supporting authority |
| `yaka-3.0-prefreeze-release-manufacturing-and-sourcing-checklist.md` | 封版、投板、SMT、采购、首板顺序 | manufacturing authority |
| `yaka-3.0-procurement-and-consignment-list.csv` | 精确采购/客供执行清单 | dated execution input |

`SHA256SUMS.txt` 在复制附件后生成，并与飞书上传结果一并登记。
